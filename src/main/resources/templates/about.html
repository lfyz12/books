О приложении

Приложение

«Книжный каталог» — веб-приложение для учёта книг и книжных магазинов. Пользователь может вести список магазинов и книг (название, автор, жанр, год издания, цена, количество), рассчитывать стоимость покупки со скидкой и доставкой, просматривать журнал своих действий.

В приложении есть три роли: READ_ONLY — только просмотр (выдаётся при регистрации), USER — работа только со своими записями, ADMIN — полный доступ ко всем данным и назначение ролей.

Технологии

  • Java 21, Spring Boot 3.5
  • Spring MVC, Thymeleaf, Bootstrap 5
  • Spring Data JPA (Hibernate), база данных H2
  • Spring Security — вход, роли, шифрование паролей BCrypt
  • Spring Boot Actuator — мониторинг приложения
  • Lombok, Maven
